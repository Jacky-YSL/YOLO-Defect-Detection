## 二、模型评估指标

后续实验主要记录以下指标。

| 指标 | 含义 |
|---|---|
| 精确率（Precision） | 模型预测为缺陷的目标中，实际正确的比例 |
| 召回率（Recall） | 数据集中实际存在的目标中，被模型成功检测出来的比例 |
| mAP@50 | 在 IoU 阈值为 0.50 时计算的平均精度均值 |
| mAP@50-95 | 在 IoU 阈值 0.50 至 0.95 范围内计算的平均精度均值 |
| 推理时间 | 模型完成一次推理所需的时间，需要注明测试条件 |

其中：

- 精确率较低，可能意味着误检较多。
- 召回率较低，可能意味着漏检较多。
- mAP@50 反映模型在较宽松定位标准下的整体检测表现。
- mAP@50-95 对目标定位精度的要求更严格。

后续还需要关注每个缺陷类别的精确率、召回率和检测效果，避免只看整体指标而忽略某些类别的明显问题。

推理时间必须在明确的硬件、输入尺寸和测试条件下记录，才能进行公平比较。

## 五、实验记录规范

每次完成实验后，应记录以下内容：

1. 实验编号和实验目的。
2. 模型结构及预训练权重。
3. 数据集和配置文件。
4. 训练参数与软件版本。
5. 实际评估指标。
6. 训练曲线和相关可视化结果。
7. 误检、漏检和其他典型错误。
8. 与此前实验的对比。
9. 实验结论和下一步计划。

无论实验结果好坏，都应如实记录。

失败的实验同样有价值，因为它们可以帮助分析数据质量、模型行为以及训练配置中存在的问题。
