#### 2.3 完成 YOLO 数据集配置

已经完成 `data.yaml` 文件的初步配置。

```yaml
path: D:/AI_Projects/datasets/NEU-DET-YOLO
train: images/train
val: images/val

nc: 6
names:
  0: crazing
  1: inclusion
  2: patches
  3: pitted_surface
  4: rolled-in_scale
  5: scratches
```

配置内容说明：

- `path`：数据集的根目录。
- `train`：训练图片相对于数据集根目录的路径。
- `val`：验证图片相对于数据集根目录的路径。
- `nc`：数据集的类别数量，此处为 6。
- `names`：每个类别对应的名称，类别编号从 0 开始。

### 三、遇到的问题及解决方法

#### 问题一：Git 仓库目录配置错误

最初，YOLO 项目使用的是上级目录 `D:/AI_Projects` 中的 Git 仓库，而该仓库的远程地址指向原来的 `D2L-Learning` 项目。

这可能导致 YOLO 项目的文件与其他项目文件混在同一个版本管理范围内。

**解决方法：**

在 `YOLO-Defect-Detection` 目录下建立独立的 Git 仓库，并将远程地址修改为对应的 YOLO GitHub 仓库。

#### 问题二：数据集标注文件与图片不匹配

检查数据集时，发现一个标注文件位于验证集目录，但对应图片位于训练集目录。

**解决方法：**

将标注文件移动到对应的训练集标注目录，然后重新运行数据集检查脚本。

重新检查后，没有再发现缺失标注文件或图片与标注不匹配的问题。
