# YOLO 钢材表面缺陷检测项目计划

## 一、项目概述

### 1. 项目目标

基于 NEU-DET 钢材表面缺陷数据集，开发一个使用 YOLO 的目标检测流程，实现对钢材表面缺陷的识别和定位。

项目将首先建立一个可复现的基线模型，再分析模型的优点和不足，并通过实验验证后续改进是否有效。

### 2. 数据集介绍

本项目使用 NEU-DET 数据集，共包含 1800 张图片，分为以下六类：

- 龟裂（crazing）
- 夹杂（inclusion）
- 斑块（patches）
- 麻点表面（pitted_surface）
- 氧化铁皮压入（rolled-in_scale）
- 划痕（scratches）

当前数据划分：

- 训练集：1440 张图片。
- 验证集：360 张图片。

### 3. 技术栈

项目初步计划使用：

- Python：编程语言。
- PyTorch：深度学习框架。
- YOLO：目标检测模型。
- Git 和 GitHub：代码版本管理。
- Markdown：项目文档编写。

具体使用哪个 YOLO 版本和模型规模，需要在基线训练前确定。

## 五、项目开发原则

1. 训练前先检查数据和配置，避免把时间浪费在路径或标注错误上。
2. 先建立基线模型，再尝试复杂的改进方法。
3. 每次实验尽量只调整少量关键因素，以便分析原因。
4. 使用实际评估结果支持结论。
5. 数据集和生成的模型权重默认不直接提交到 GitHub。
6. 在完成有意义的代码、配置或文档修改后，及时进行 Git 提交。
7. 持续维护开发日志和实验记录，保证项目过程可追溯。
